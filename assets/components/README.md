# Reusable components

Proven layouts, SVG motifs and CSS snippets that runs can reuse. Add one only after it worked in a published post; one comment line at the top saying when to use it.

- `verse-brand.css`: @homingo.verse logo palette tokens, scene base, label, headline, and the `.v-mark` position. Link in every verse reel and story.
- `verse-mark.svg.html`: the orbit-dot mark SVG; paste inside `<div class="v-mark">…homingo.verse</div>` on every verse scene.
