Myth vs fact

One flag. Three lengths.Myth: a string's length is the characters you see.

🇮🇳
You see 1 character.
It is 2 code points.
// JavaScript
console.log('🇮🇳'.length)
# Python
print(len('🇮🇳'))
Real output
JS  4
Py  2
JavaScript counts UTF-16 units, Python counts code points. A flag is two code points, and each takes two units in UTF-16.
