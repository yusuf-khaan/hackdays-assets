■ SURGELABS
Halloween · Explainer

It is dead. It is still in your process table.A zombie process has exited, but its parent never read the result. You cannot kill what is already dead.

$ ps aux  ·  illustrative output
PID 4101
parent  worker.py  // running
PID 4102
Z  <defunct>  // exited, never read
$
kill -9 4102  // no effect
1. child exits
2. parent calls wait()
3. entry removed
The fix: the parent reaps its children.
