// the rule nobody told you

Some disks don’t care about capital letters.

macOS (APFS default)Button = button
Windows (NTFS default)Button = button
Linux (CI, servers)Button ≠ button
On a case-insensitive disk Git sets core.ignorecase=true, so a rename that only changes case can slip past it.
Which means the rename… never happened.
// 11:52 · root cause
07 / 08

You renamed button.js to Button.js.

Git never noticed.
Your Mac never cared.
CI cared a lot.
