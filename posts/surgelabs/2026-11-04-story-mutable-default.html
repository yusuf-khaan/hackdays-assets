Same call. Different answer.Nothing changed between the two lines. Except the list.

def add(item, box=[]):
    box.append(item)
    return box

> print(add('a'))
> print(add('b'))
Real output
['a']
['a', 'b']
The default list is created once, when def runs, then shared by every call. Use box=None and make a new list inside.
