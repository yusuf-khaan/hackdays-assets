02 / 08
What happened

On 9 Oct, the whole Deno team said it's joining Cloudflare.

Deno is a JavaScript and TypeScript runtime from Ryan Dahl, the engineer who created Node.js.
Big news on its own. But builders shouldn't stop at the headline. Inside the announcement were two deadlines, for two different things.
Deadline one is the gentle one →
03 / 08
Clock 01 · Runtime
// the deno runtime

One more year of fixes. Then official work stops.

Reported plan
12 months of bug fixes and security updates. After that, official development ends.
But
The code stays open source. Anyone can still run it, fork it, keep it alive.
So the code doesn't die. Clock two is different →

The real prize
// celld, released by deno in august

A way to run Cloudflare Workers on your own servers.

celld
An open-source, self-hostable take on the Workers model, Durable Objects included.
The plan
Merge it into workerd, Cloudflare's open-source Workers runtime.

07 / 08
Lab notes · Exit plan

3 checks before the deadline email arrives.

[01]
Can it run on a box you control?A container or an open runtime, tested once, not assumed.
[02]
Can you export your data today?Database, files, env config. A real export, not a promise.
[03]
Where are the vendor-only APIs?Keep them behind one thin adapter, so a move is one file of changes.
