Myth vs fact

You deleted the key from the repo. Git still has it.Myth: “I committed the removal, so it’s gone.”

Run locally · fake keygit 2.43
$ git rm .env && git commit -m "remove env"
$ git log --oneline -- .env
2ef03be remove env
00f8681 add env
$ git show 00f8681:.env
API_KEY=sk_test_demo
Fix: treat a committed secret as leaked. Rotate the key first, then clean the history.
Sources: GitHub Docs (removing sensitive data), Oasis Security
