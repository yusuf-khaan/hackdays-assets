# Homingo content system

Instagram carousels and stories for @homingo.verse, @homingo._, @homingo.hackdays and @surgelabs_, designed in HTML, rendered here and published through Instahook by scheduled runs. The system learns from its own results and improves itself.

- `playbook/RUN.md`: schedule and step-by-step procedure (start here)
- `playbook/FEEDBACK.md`: the owner's notes, which override everything else
- `playbook/CAROUSEL.md`: hook and carousel craft, with the quality gate
- `playbook/TRENDS.md`: spotting what people are reacting to right now
- `playbook/LEARNING.md`: the learning loop, weekly review and guardrails
- `playbook/<account>.md`: facts, categories, visuals and voice per account
- `learnings/<account>.md`: what has worked, experiments, backlog (updated by the runs)
- `data/<account>.jsonl`: one line per published post: the evidence
- `reviews/`: weekly review reports
- `tools/carousel.js`: render a deck to slides + contact sheet + layout warnings
- `tools/render.js`: render a single image (stories)
- `tools/stats.js`: performance summary for the learning loop
- `posts/verse/example-rani-ki-vav.html`: a reference deck
